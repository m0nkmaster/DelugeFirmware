<Badge text="c1.4 Feature" variant="tip" />

The Deluge can act as a USB audio interface. When it's connected to a computer over its USB type-B port, it shows up
as a class-compliant audio device alongside its existing USB MIDI ports, so no driver is needed. You can:

- play audio from your computer through the Deluge's outputs
- record the Deluge's output into your computer
- record and monitor audio from your computer in an audio clip, just like the line input

This branch also supports experimental [USB host input](#experimental-usb-host-input): the Deluge can receive audio
from an attached device such as a TONEX, without a computer. `COMPUTER AUDIO` controls audio with a computer;
`COMMUNITY FEATURES > USB HOST AUDIO` controls capture from attached audio devices.

## Format

|             | From computer to Deluge | From Deluge to computer |
| ----------- | ----------------------- | ----------------------- |
| Channels    | 2 (stereo)              | 2 (stereo)              |
| Sample rate | 44.1 kHz                | 44.1 kHz                |
| Bit depth   | 24-bit                  | 24-bit                  |

The Deluge's own sample clock sets the rate for audio going to the computer. For audio coming from the computer, the
Deluge offers two modes, and the computer picks whichever it supports:

- **Following the Deluge's clock.** Computers that support this (such as macOS) send audio at exactly the Deluge's
  rate, so it's passed straight through.
- **Following the computer's clock.** Computers that can't follow the Deluge's clock, such as Windows, send at their
  own rate instead. The Deluge occasionally drops or repeats a single sample to stay in step, which isn't normally
  audible.

<Aside type="caution">Windows support hasn't been confirmed yet.</Aside>

## Setting up

1. Connect the Deluge to your computer with a USB cable.
2. Choose the Deluge as an audio input and/or output device in your computer's sound settings or your DAW. On macOS
   it's listed in Audio MIDI Setup.

The Deluge's USB MIDI ports keep working as before.

## Settings

USB settings are in `SETTINGS > USB` (`USB` on 7SEG). Compared with upstream main, this branch moves the existing
`USB AUDIO` menu inside `USB`, adds `MODE` and `STATUS`, and renames the audio controls:
`ENABLED` becomes `COMPUTER AUDIO`, `INPUT` becomes `DIRECT MONITORING`, and `OUTPUT` becomes `SEND TO COMPUTER`.
These menus remain visible with `USB HOST AUDIO` off.

| Setting     | 7SEG   | Purpose                                                                                      |
| ----------- | ------ | -------------------------------------------------------------------------------------------- |
| `MODE`      | `MODE` | `COMPUTER` (`COMP`) connects to a computer; `HOST` (`HOST`) manages attached USB devices.    |
| `STATUS`    | `STAT` | Shows computer mode, or host-audio progress/errors. Uses short codes on 7SEG (listed below). |
| `USB AUDIO` | `USBA` | Opens the audio controls below.                                                              |

The mode applies to both USB MIDI and audio. Changing it reconnects USB without restarting the Deluge or song;
USB audio/MIDI is interrupted. Connect DC power before selecting Host, and disconnect any computer first. A DC-power
reminder appears when Host is selected. The mode is session-only; the next boot uses normal connection detection.

On 7SEG, mode-change popups use `WAIT` while switching, `DC` as the host-power reminder, `DISC` if a computer must
be disconnected first, `BUSY` if USB cannot switch yet, and `FAIL` if the controller cannot start. Detailed host-audio
messages appear on OLED; 7SEG uses the status codes below.

Inside `SETTINGS > USB > USB AUDIO`:

| Setting             | 7SEG   | Options                                                                                    |
| ------------------- | ------ | ------------------------------------------------------------------------------------------ |
| `COMPUTER AUDIO`    | `COMP` | On (default), off: whether the Deluge offers audio to a computer.                          |
| `DIRECT MONITORING` | `MONI` | On (default), off: hear incoming USB audio directly through the outputs.                   |
| `SEND TO COMPUTER`  | `SEND` | `MAIN MIX` (default, `MIX`) or `LINE IN` (`LINE`). Does not send audio to a hosted device. |

### Automatic detection and the Mode selector

**The Deluge automatically chooses its USB role at startup only.** It first checks for an attached device to host.
If none is detected, it switches to Computer mode. Plugging in a device later does not automatically change that role.

- With your audio device connected at power-on and detected during startup, Host mode is selected automatically.
- If you start with nothing attached and connect a TONEX later, select `MODE > HOST` to use it without rebooting.
- To move from hosting a device to a computer connection, disconnect the device, select `MODE > COMPUTER`, then
  connect the computer. To go back, disconnect the computer before selecting Host.

`MODE` applies to both MIDI and audio. It remains useful with `USB HOST AUDIO` off for switching to a USB MIDI
controller without rebooting. Changing the host-audio toggle does not select Host mode for you.

### What USB Host Audio enables

`SETTINGS > COMMUNITY FEATURES > USB HOST AUDIO` (`HAUD`) controls whether the Deluge can recognise and capture
compatible audio devices **while in Host mode**. It is saved with the community preferences and defaults to off to preserve MIDI on combined audio/MIDI devices.
Explicit saved preferences are retained; this default applies when the setting is absent or reset.

| USB Host Audio | USB MIDI devices | Compatible USB audio devices |
| --- | --- | --- |
| Off | MIDI hosting remains available. | Audio capture is disabled. |
| On | MIDI hosting remains available; see the combined-device limitation below. | Audio can be monitored and recorded through `USB INPUT`. |

Changing this setting while hosting reconnects the attached USB devices and briefly interrupts their MIDI/audio.
It leaves computer-mode audio and MIDI unaffected. `COMPUTER AUDIO` is the separate setting for audio with a computer.
The menu layout stays the same whichever position the toggle is in.

### Devices that carry both audio and MIDI

Some instruments and interfaces carry both audio and MIDI through one USB cable, such as the
[Teenage Engineering OP-XY](https://teenage.engineering/products/op-xy). These are often called composite devices.
**This branch cannot currently capture audio and use USB MIDI from the same attached device simultaneously.**
With `USB HOST AUDIO` on, the audio driver takes priority for devices it claims. Turn it off to make the device
available to the MIDI driver. This limitation applies when the Deluge is hosting; audio and MIDI together still work
when the Deluge is connected to a computer.

Separate MIDI and audio devices through a hub are intended to coexist, but that setup still needs hardware testing.
The OP-XY is an example of a combined device, not a confirmed compatible audio source for this branch. Audio operation
has been reported working with TONEX ONE and TONEX Plug; other devices need testing.

## Turning computer audio off

Computer audio is on by default. To turn it off, set `SETTINGS > USB > USB AUDIO > COMPUTER AUDIO` to off. The Deluge then connects to
your computer as a USB MIDI device only. This setting does not disable capture from a hosted audio device.

The setting takes effect the next time computer mode starts, either after restarting the Deluge or switching USB
mode away from `COMPUTER` and back. Disconnect the computer before switching to `HOST`, then reconnect it after
returning to `COMPUTER`. Unplugging and reconnecting the cable alone does not rebuild the audio configuration.
This setting does not disable experimental host capture; that has its own community preference.

<Aside>
  If you've used the Deluge over USB MIDI before, your computer may treat it as
  a new device the first time you connect it with this firmware, since it now
  describes itself differently. Unplugging and reconnecting it should sort out
  any problems with it not appearing.
</Aside>

## Playing audio from your computer

Audio from the computer is mixed straight into the Deluge's main outputs and headphones, after the song's master
volume and effects. This is on by default, and can be turned off with `SETTINGS > USB > USB AUDIO > DIRECT MONITORING`. When it's off,
you'll only hear the computer's audio through an audio clip that's monitoring it.

This audio is **not** sent back to the computer as part of the Deluge's output, so you won't get an echo. To put the
computer's audio through the Deluge's effects, monitor it with an audio clip instead (see below).

When an audio clip is monitoring the USB input (see below), the computer's audio is heard through that track instead,
with its volume and effects. The Deluge stops mixing it straight to the outputs while that's happening, so you never
hear it twice. Mixing straight to the outputs comes back by itself once nothing's monitoring the USB input, for example
when a sampler clip has finished recording.

## Recording the Deluge into your computer

`SETTINGS > USB > USB AUDIO > SEND TO COMPUTER` sets what the computer receives:

- **`MAIN MIX`** (the default) is the Deluge's final stereo output: the same audio that goes to the main outputs,
  including any monitored inputs, but not the computer's own audio when it's mixed straight to the outputs.
- **`LINE IN`** is the Deluge's line input (or mic) as it arrives, before any of the Deluge's processing. This turns
  the Deluge into a simple audio interface for whatever's plugged into it. The internal mic only has one channel, so
  it's sent to both sides.

## Recording audio from your computer in an audio clip

USB can be chosen as the source for an audio clip, like the line input or another track:

1. In an audio clip, open the Audio Clip Sound Menu (:key[Shift + Select]).
2. Go to `AUDIO SOURCE` and select `USB INPUT` (`USB` on 7SEG).

USB is always a stereo source. Unlike the line input, it isn't normalized after recording, since the computer's audio
already arrives at the level it was meant to be.

Monitoring follows the audio output mode, as for any other source (see
[Select Audio Clip Source and Monitoring](/features/community_features#317---select-audio-clip-source-and-monitoring)):
`SAMPLER` and `LOOPER` monitor the USB input, while `PLAYER` doesn't.

<Aside type="caution">
  If an audio clip is monitoring the USB input, the computer's audio becomes
  part of the Deluge's output, which is sent back to the computer when `SEND TO
  COMPUTER` is `MAIN MIX`. If your DAW is also playing its Deluge input back out
  to the Deluge, that makes a feedback loop. Turn off input monitoring in the
  DAW, or use the `PLAYER` mode on the clip.
</Aside>

Recording a sample from a synth or kit's sample menu still uses the analogue line/mic input automatically; it does
not yet offer a USB source selector. To use a USB recording in a kit, record it into an audio clip first, **save the
song**, then load the recorded sample from `SAMPLES/CLIPS` into a kit row through the sample browser. Before saving,
audio-clip recordings live in `SAMPLES/CLIPS/TEMP`, which the Deluge's browser deliberately prevents you from entering.

## Latency

Audio from the computer is buffered by about 6 ms (256 samples) on the Deluge before it's played or recorded, which
keeps it smooth when the Deluge is busy. Audio going to the computer is buffered by about 2 ms. Your computer adds its
own buffering on top of both, which you can usually set in your DAW.

## Experimental USB host input

This build also includes experimental capture from a class-compliant USB audio device connected directly to the
Deluge. This is separate from using the Deluge as your computer's audio interface.

1. Power the Deluge from its DC supply and disconnect any computer from its USB port.
2. Connect the audio device using the Deluge's USB host adapter and a USB data cable.
3. Enable `SETTINGS > COMMUNITY FEATURES > USB HOST AUDIO` (`HAUD` on 7SEG).
4. Check `SETTINGS > USB > MODE` (`USB > MODE` on 7SEG). Select `HOST` if startup detection has not already done so.
5. Choose `USB INPUT` as the audio clip's source and use `SAMPLER` or `LOOPER` to monitor it.

Changing Mode reconnects USB without restarting the Deluge or song. The selection lasts for this session;
the next boot uses startup detection again. Connect DC power and disconnect any computer before selecting Host.
The Deluge shows a DC-power reminder but cannot check whether the supply is connected.

The mode reports the USB role, not whether an audio device is streaming. Open
`SETTINGS > USB > STATUS` (`USB > STAT` on 7SEG) to check capture startup. With the community capability disabled,
in Host mode this shows “Host mode: audio disabled” (`OFF` on 7SEG). Otherwise it distinguishes
unsupported formats, clock/interface setup errors, waiting for audio, and stopped transfers. `Receiving USB audio`
means audio data is arriving, though it may contain silence. To hear USB input through an audio clip, use `SAMPLER`
or `LOOPER` monitoring.

| 7SEG status | Meaning                                             |
| ----------- | --------------------------------------------------- |
| `COMP`      | Computer mode                                       |
| `OFF`       | Host mode, audio capability disabled                |
| `NONE`      | No audio device selected                            |
| `FMT`       | No supported audio format                           |
| `SIZE`      | Device configuration descriptor too large           |
| `BUSY`      | Audio pipe already in use                           |
| `INIT`      | Configuring audio                                   |
| `CLCK`      | Audio clock setup failed                            |
| `INTF`      | Audio interface setup failed                        |
| `WAIT`      | Waiting for audio packets                           |
| `RECV`      | Receiving audio packets (which may contain silence) |
| `STOP`      | Audio transfer stopped after an error               |

Developer builds also show packet counts (`PKTS`) and, on OLED, maximum audio interrupt time. The packet count on
7SEG updates when the status changes or the page is reopened.

Support is currently limited to one full- or high-speed USB Audio Class 1 or 2 capture device at 44.1 kHz. The host
negotiates the device's bus speed. High-speed capture uses interrupt-driven reception for 125-microsecond packets;
full-speed capture uses 1-millisecond packets. Only `bInterval=1` and one transaction per interval are supported.
Capture accepts signed little-endian Type I PCM with 1–4 bytes per sample and up to 32 channels, with valid bits
left-justified in each sample slot. Complete configuration descriptors must fit within 1024 bytes.
The selected format must fit within one packet: at most 1023 bytes at full speed or 1024 bytes at high speed.
UAC1 devices must advertise 44.1 kHz; devices with multiple or continuous rates must accept setting and reading back
that rate. UAC2 requires a terminal connected directly to a readable clock source; writable clocks are set to
44.1 kHz and read back, while read-only clocks must already report that rate. Clock selectors and multipliers are
not supported. Mono is duplicated to stereo; for larger streams, the first two channels are used. Sending audio back
to the device, sample-rate conversion, and [simultaneous USB MIDI on the same audio device](#devices-that-carry-both-audio-and-midi) are not supported.

<Aside type="caution">
  USB audio operation with TONEX ONE and TONEX Plug has been reported working by
  the user who tested this branch. Both devices' captured descriptors are also
  covered by regression tests. Other devices and operating conditions still need
  testing, including sustained recording under CPU load, repeated role changes,
  and MIDI/hub compatibility after high-speed negotiation. Occasional flaky
  connections have also been reported; their cause is unresolved. USB power
  depends on the Deluge's hardware and external supply; firmware cannot increase
  the available current. This is not yet universal USB audio compatibility.
</Aside>
